# DA-1701 Absorber AI (Loyixa-SGCC)

Amin bilan gazni tozalash absorberi DA-1701 uchun operator trenajyori: mnemosxema, 3D, trendlar, AI diagnostika,
hodisani qayta ko‘rish, jurnal, ssenariylar, Anonim/Haqiqiy (parol bilan) rejim.

- Brauzerda: `index.html` ni oching yoki `npm run build` → `dist/DA-1701-Absorber-AI.html` (internetsiz).
- Windows: Releases → `DA-1701-Absorber-AI-Setup-<versiya>.exe`.
- Testlar: `npm test`, `npm run e2e`.

Asl yuklangan fayl: `source/Zavod_jarayoni_DA-1701_Ananim_v1.html`.
